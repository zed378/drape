## Scope

Continued the existing Rust CI implementation under the owner's request for parallel implementation and a single testing agent. The orchestrator handed off `.github/workflows/rust.yml`; legacy CI and source remain preserved. No commit, PR, merge or hosted workflow execution is implied.

The separate Rust Windows x64 workflow selects `windows-2022`, exact Rust 1.90.0 MSVC and SHA-pinned checkout/Python/artifact actions. Its single job runs the locked Release build, rustfmt, denied-warning Clippy, workspace tests, actual Cargo boundary mutations, deliberate formatting/warning rejection, Core line coverage, licence/advisory checks and redacted Git-history secret scanning sequentially. It uses no writable shared cache or signing credentials. Native desktop manipulation is absent.

`scripts/ci/install-tools.ps1` pins cargo-llvm-cov 0.6.21, cargo-deny 0.21.0 and Gitleaks 8.24.3; it checks the Gitleaks archive against its versioned upstream checksum file. The workflow archives build/environment/helper versions, coverage/test reports, Cargo lock/toolchain files and third-party notices. `deny.toml` scopes the target to Windows x64, rejects unknown sources and retains the documented Slint royalty-free exception and attribution requirements.

The coverage gate rejects missing Core source files, empty reports, coverage below 80% and impossible/noninteger counters. The added counter test prevents percentages above 100% or negative counters from satisfying the gate. Existing format/Clippy probes compile an isolated dependency-free crate, verify clean-source success and then require actual tool rejection of deliberate mutations.
