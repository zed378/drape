## What Surprised Me

- `XPlat Code Coverage` needs `coverlet.collector` as an explicit package; without it the collector
  name is unknown and the run silently produces no report.
- Avalonia 12: `SystemDecorations` is obsolete (use `ExtendClientArea*`), `BoolConverters.ToOpacity`
  does not exist, `ExtendClientAreaChromeHints` is not a Window property (use
  `ExtendClientAreaTitleBarHeightHint="-1"`), `AppBuilder.StartWithClassicDesktopLifetime` returns
  int, `SetupWithoutStarting` returns the builder, and `Application` has no `Shutdown()`.
- Constructing an Avalonia `Window` without a platform throws `Unable to locate
  IWindowingPlatform`. The headless platform must be set up via `AppBuilder ... UseHeadless ...
  SetupWithoutStarting()` first.
- The 20 ms budget fails at ~24 ms median on this machine. Single-run timing also showed 23–26 ms
  across runs — consistent, not flaky.
