## Change and review

`crates/drape-core/src/layout.rs` adds validated Rect/Monitor/StoredLayout/ResolvedLayout, typed errors, clamp/fractions/resolve/snap operations. The root architect adds only its public module export. Core remains std-only and platform-free. Original stored bounds and reference work-area dimensions are borrowed unchanged across resolution/DPI/monitor transitions. Exact opaque identity matches uniquely; missing/ambiguous matches use one primary, otherwise fail explicitly. No native monitor identity stability is assumed.

Snap selects the nearest candidate independently per axis within an inclusive 8 DIP; Alt bypasses it. Equal distances prefer work-area edges, then supplied neighboring panel order, then grid. Neighbors require perpendicular overlap. Snap is separate from presentation clamping. Clamp retains at least 40 DIP on each axis where available, keeps the top edge reachable, enforces 120x80 minimum and defines tiny-area behavior. Geometry and arithmetic overflow return errors.

Architect static review found no blocker in the pure boundaries, immutable snapshot, explicit topology handling and checked arithmetic. QA behavioral review and executable evidence are separate.
